# ラーメン帳

訪れたラーメン屋を地図とカードで記録する、個人用のiPhone向けWebアプリ（PWA）です。

- 記録と写真は端末内（IndexedDB）にだけ保存され、サーバーには送信されません
- 店舗検索: [OpenPOI API](https://openpoiapi.com/attribution.html)（Overture Maps Foundation ほか）
- 地図: [国土地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)（淡色地図）
- 地図表示: [Leaflet](https://leafletjs.com/)
- アイコン: [Phosphor Icons](https://phosphoricons.com/)（MIT License）
